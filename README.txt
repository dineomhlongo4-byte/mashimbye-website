MASHIMBYE TOURS WEBSITE
=======================

FILES
- index.html       Home page
- about.html       About Mashimbye Tours
- services.html    Services
- booking.html     Booking enquiry form
- contact.html     Contact details
- styles.css       Website design and responsive layout
- script.js        Mobile menu, booking form and footer year
- image.jpg.jpg    Original Mashimbye Tours promotional artwork
- IMG_7665.jpg.jpg Original vehicle image

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.

HOW TO PUBLISH WITH GITHUB / NETLIFY
1. Upload all files and both images to the root of your GitHub repository.
2. Make sure the home page is named exactly index.html.
3. In Netlify, import the GitHub repository.
4. Set the build command to blank and the publish directory to the repository root (or ".").
5. Deploy the site.

BOOKING FORM
The booking form opens WhatsApp with the customer's trip details pre-filled. The customer must press Send in WhatsApp. This is an enquiry only; it does not confirm a booking or take payment.
